# Modelo de briefing interno - KIIRU

Use este modelo para padronizar tarefas no Kiiru:

```text
OBJETIVO:

TEXTO PRINCIPAL SUGERIDO:

INFORMACOES OBRIGATORIAS:

DIRECAO VISUAL:

EVITAR:

ENTREGAVEL:
```

## Criterio de qualidade

Um briefing interno bom precisa permitir que designer, copywriter ou agente criativo entendam rapidamente:

- o que deve ser produzido;
- para qual cliente;
- qual mensagem central a peca precisa carregar;
- o que deve aparecer obrigatoriamente;
- qual direcao visual seguir;
- o que deve ser evitado;
- qual formato final entregar.

## Regra operacional

Antes de criar ou atualizar briefing no Kiiru, consultar:

- Cofre do cliente;
- briefing anterior da tarefa, se existir;
- padrao editorial da LÓGIKA;
- restricoes de imagem, tom e dados sensiveis.
