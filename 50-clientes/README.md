# 50-clientes

## Princípio
Cada cliente/frente tem contexto próprio. Agentes não devem cruzar contexto entre clientes sem autorização/necessidade clara.

## Frentes principais
- `10-saude-sao-sebastiao/`
- `20-camara-municipal/`
- `30-sindss/`
- `40-outros-vereadores/`
- `50-outros-clientes/`

## Regra
Novo conteúdo de cliente deve nascer aqui. Conteúdo legado será migrado em lotes pequenos, com origem registrada.
