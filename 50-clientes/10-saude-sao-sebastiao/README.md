# Saúde São Sebastião

## Finalidade
Organizar saúde pública municipal, conteúdo institucional e operação da frente Saúde São Sebastião.

## Regra de acesso
Agentes podem escrever aqui quando atuarem nesta frente, usando apenas o contexto necessário e sem misturar dados de outros clientes.

## Arquivos canônicos
- `contexto.md` — resumo vivo da frente.
- `fontes.md` — onde consultar materiais originais e legados.
- `pendencias.md` — pendências específicas da frente.
- `handoffs.md` — passagens e histórico de agentes.
- `10-contexto/operacional/README.md` — entrada operacional atual para agentes.

## Rota atual para agentes

1. Comece por `10-contexto/operacional/README.md`.
2. Consulte os índices de `00-indice/` para localizar unidades, setores, editorial, materiais aprovados e padrão de nomes.
3. Use `20-fontes/base-legada-f1-frente/` apenas como fonte histórica ou para auditoria de origem.
4. Salve novas entregas em `30-entregas/`, separando aprovado, rascunho e legado.
