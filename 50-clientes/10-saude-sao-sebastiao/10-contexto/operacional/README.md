# Saúde São Sebastião - Operacional

Esta é a entrada principal para agentes consultarem a estrutura operacional da Secretaria de Saúde.

## Comece por aqui

1. Para saber **o que cada setor faz**:
   `01-matrizes/matriz-competencias-por-setor.md`

2. Para saber **onde cada setor entra em pauta/conteúdo**:
   `01-matrizes/matriz-setores-pilares-fontes.md`

3. Para visão geral de unidades, PSFs e setores:
   `02-visoes-gerais/`

4. Para fichas individuais por setor:
   `03-fichas-setores/fichas-operacionais/`

## Estrutura simplificada

- `00-guias/` — avisos e guias de navegação.
- `01-matrizes/` — matrizes principais de setores, competências e unificação.
- `02-visoes-gerais/` — arquivos amplos sobre UBSs, PSFs, recepção/regulação e setores complementares.
- `03-fichas-setores/` — materiais por setor, separados pelo tipo de documento.
- `90-readmes-categorias/` — READMEs antigos das categorias, mantidos por rastreabilidade.

## Como ler fichas por setor

As fichas foram achatadas para evitar caminhos profundos.

Exemplo:

`03-fichas-setores/fichas-operacionais/03-servicos-especializados-diagnostico--laboratorio-municipal.md`

Significa:

- grupo: `03-servicos-especializados-diagnostico`
- setor: `laboratorio-municipal`
- tipo: `ficha-operacional`

## Regra para agentes

Não procurar primeiro em pastas antigas profundas. Para trabalho operacional atual, use esta pasta:

`50-clientes/10-saude-sao-sebastiao/10-contexto/operacional/`

As estruturas antigas esvaziadas foram preservadas apenas em:

`50-clientes/10-saude-sao-sebastiao/90-arquivo/estrutura-operacional-antiga-2026-07-30/`

Elas não devem ser usadas como fonte ativa.
