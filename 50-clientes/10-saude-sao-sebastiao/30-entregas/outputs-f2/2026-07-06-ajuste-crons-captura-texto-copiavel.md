# Ajuste dos lembretes — captura/cópia de texto no Telegram

Jadielson esclareceu que a facilitação desejada era para **captura/cópia do texto**, não apenas para captação de imagens.

## Ajuste aplicado nos crons
Os jobs de 06h e 21h foram atualizados para entregar os textos finais em blocos copiáveis, preferencialmente code blocks, separados das instruções de cena.

## Nova estrutura esperada
- Resumo operacional curto.
- Checklist rápido de captação/preparação.
- Para cada story:
  - `Capture:` com orientação visual objetiva.
  - `Copiar texto:` com bloco limpo contendo apenas o texto final.
- Para reel:
  - `Copiar gancho:`
  - `Copiar legenda:`
- Para post/feed:
  - `Copiar headline:`
  - `Copiar legenda:`
- Cuidados LGPD/validação.
- Fonte.

## Regras de texto
- Não misturar instrução de captação com texto final.
- Evitar parágrafos longos.
- Deixar textos prontos para copiar/colar em card, story, legenda ou WhatsApp.
