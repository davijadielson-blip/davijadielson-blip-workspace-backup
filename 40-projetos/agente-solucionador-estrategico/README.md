# Agente Solucionador Estrategico

Esta pasta centraliza os problemas, diagnosticos, decisoes e planos gerados no topico `PROJETOS > Agente Solucionador Estrategico`.

Objetivo: cada assunto importante tratado aqui deve ter um lugar no Cofre para consulta futura, continuidade, debate e acompanhamento.

## Como usar

- `casos/`: um arquivo por problema ou assunto resolvido/em teste.
- `templates/`: modelos para registrar novos casos.
- Arquivos relacionados podem continuar nas pastas corretas do Cofre, mas o caso deve apontar para eles.

## Regra de registro

Todo novo problema relevante deste topico deve virar um caso quando gerar pelo menos um destes itens:

- diagnostico;
- decisao;
- plano de acao;
- rotina;
- checklist;
- teste/piloto;
- proximo passo relevante;
- contexto que precisa ser resgatado depois.

Cada caso deve conter:

- problema;
- contexto;
- decisoes tomadas;
- plano/teste;
- status;
- proximos passos;
- arquivos relacionados;
- fonte.
