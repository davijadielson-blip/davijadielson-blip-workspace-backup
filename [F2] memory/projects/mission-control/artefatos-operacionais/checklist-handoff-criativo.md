# Checklist de Handoff Criativo — Lógika / Frentes Institucionais

**Status:** v0.1 ativo  
**Uso:** toda entrega criativa antes de edição, revisão, publicação ou entrega ao cliente.

## 1. Identificação

- [ ] Frente/projeto:
- [ ] Tipo de entrega: post, reels, vídeo, cobertura, roteiro, peça, legenda, proposta etc.
- [ ] Dono da entrega:
- [ ] Aprovador:
- [ ] Prazo:
- [ ] Fonte no Cofre:

## 2. Briefing mínimo

- [ ] Objetivo da peça está claro.
- [ ] Público-alvo definido.
- [ ] Formato/plataforma definidos.
- [ ] Tom de voz definido.
- [ ] CTA ou mensagem central definido.
- [ ] Restrições e cuidados informados.

## 3. Materiais

- [ ] Fotos/vídeos disponíveis.
- [ ] Áudios/narração disponíveis, se houver.
- [ ] Identidade visual/referências localizadas.
- [ ] Texto-base/legenda/roteiro localizado.
- [ ] Links e arquivos salvos fora do Cofre se forem binários; no Cofre apenas `.md`.

## 4. Produção

- [ ] Responsável por edição/design definido.
- [ ] Critério de pronto definido.
- [ ] Prazo de primeira versão definido.
- [ ] Prazo de revisão definido.

## 5. Aprovação e publicação

- [ ] Quem aprova está definido.
- [ ] Canal de publicação definido.
- [ ] Data/horário sugeridos.
- [ ] Registro pós-publicação será feito.

## 6. Critério de pronto

A entrega só sai do handoff quando tiver:

1. briefing;
2. material;
3. dono;
4. prazo;
5. aprovador;
6. critério de pronto;
7. fonte no Cofre.
