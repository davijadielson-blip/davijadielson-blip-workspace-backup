**Projeto:** Biblioteca de templates de produção de vídeo / Premiere.

## Norte

Criar uma primeira biblioteca utilizável com **5 templates de vídeo vertical para Premiere**, derivados de vídeos reais de alta performance, cada um com ficha de estrutura, referência viral, roteiro-base, timeline marcada e teste prático exportado.

## Critério de conclusão da v1

A v1 estará concluída quando existirem:

- 5 templates documentados;
- 5 projetos-base ou timelines no Premiere;
- 1 vídeo-teste exportado por template;
- cada template organizado na lógica `Gancho/Abertura → Desenvolvimento/Solução → CTA/Encerramento`;
- índice geral e guia rápido de uso;
- arquivos de Premiere armazenados fora do Cofre, em Drive/pasta de produção, com documentação em Markdown no Cofre.

## Decisões já tomadas

1. O projeto é sobre **templates de produção de vídeo**, principalmente para Premiere.
2. A estrutura narrativa padrão aprovada é em **3 blocos**:
   - Gancho / abertura;
   - Desenvolvimento / solução;
   - CTA / encerramento.
3. Desenvolvimento e solução ficam juntos no mesmo bloco macro.
4. O projeto deve copiar **mecanismo, estrutura, ritmo e lógica**, não identidade visual proprietária, música, roteiro literal ou marca.
5. O escopo inicial sugerido é vídeo vertical curto, Reels/Shorts/TikTok, 30s a 60s.
6. A v1 deve começar com 5 tipos de template:
   - Template 01 — Storytelling informativo vertical, referência: Nas Daily;
   - Template 02 — Desafio / transformação, referência: Jenny Hoyos;
   - Template 03 — Reveal / loop visual, referência: Zach King;
   - Template 04 — Venda direta / produto, referência: Dollar Shave Club ou Blendtec;
   - Template 05 — Institucional / causa, referência: Dove Real Beauty Sketches.
