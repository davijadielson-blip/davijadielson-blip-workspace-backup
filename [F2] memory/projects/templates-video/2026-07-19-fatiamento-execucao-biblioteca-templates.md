# Fatiamento de execução — Biblioteca de Templates de Vídeo

Data: 2026-07-19  
Tópico: PROJETOS > Templates  
Projeto: Biblioteca de templates de produção de vídeo / Premiere

## 1. Visão geral do todo

Criar uma biblioteca prática de templates de vídeo, principalmente para Premiere, baseada em vídeos reais que performaram muito bem.

A estrutura padrão aprovada é:

1. Gancho / Abertura
2. Desenvolvimento / Solução
3. CTA / Encerramento

O objetivo não é criar teoria sobre vídeo. O objetivo é transformar referências virais em modelos reutilizáveis de roteiro, edição, timeline e produção.

Hipótese assumida, a confirmar: o primeiro pacote de templates será voltado para vídeos verticais curtos, Reels / Shorts / TikTok, em 30s a 60s.

## 2. Quebra em fases, blocos ou subprojetos

### Fase 1 — Organizar a biblioteca de referências

Transformar os links já coletados em uma tabela operacional.

Categorias iniciais:
- Storytelling / mini-doc informativo
- Desafio / transformação
- Visual / reveal / loop
- Produto / venda direta
- Campanha institucional / causa
- Teste extremo / demonstração

### Fase 2 — Extrair estruturas copiáveis

Para cada referência viral, extrair:
- gancho;
- progressão do desenvolvimento / solução;
- tipo de encerramento;
- ritmo de edição;
- elementos de Premiere necessários;
- adaptação segura sem copiar identidade visual proprietária.

### Fase 3 — Criar fichas de template

Cada template precisa ter uma ficha simples:
- nome do template;
- objetivo;
- duração sugerida;
- estrutura em 3 partes;
- roteiro-base;
- slots de imagem/vídeo;
- sugestão de áudio;
- tipo de CTA;
- exemplos de referência.

### Fase 4 — Criar templates no Premiere

Transformar as fichas em timelines reais:
- sequência 9:16;
- marcadores;
- placeholders;
- tracks organizadas;
- tela de CTA;
- presets de texto/caption;
- espaço para trilha;
- exportação padrão.

### Fase 5 — Testar em produção real

Usar cada template em pelo menos 1 vídeo real.

Validar:
- tempo de edição;
- clareza da timeline;
- facilidade de troca de takes;
- qualidade final;
- se o vídeo mantém ritmo bom.

### Fase 6 — Refinar e versionar

Depois do teste:
- ajustar duração dos blocos;
- remover o que atrapalha;
- salvar versão 1.0;
- registrar instrução de uso;
- decidir quais templates entram na biblioteca oficial.

## 3. Microtarefas executáveis

### Biblioteca de referências

- Criar tabela-mãe em Markdown.
- Inserir links virais já curados.
- Colocar métrica de performance de cada vídeo.
- Marcar categoria de cada referência.
- Marcar prioridade: alta, média ou baixa.

### Análise de estrutura

Para cada vídeo prioritário:
- assistir 1 vez inteiro;
- anotar duração;
- escrever o gancho em uma frase;
- dividir em 3 blocos: gancho, desenvolvimento/solução, CTA;
- anotar cortes, captions, B-roll, ritmo e áudio;
- anotar o mecanismo copiável.

### Fichas de template

- Criar ficha do Template 01: Storytelling informativo estilo Nas Daily.
- Criar ficha do Template 02: Desafio / transformação estilo Jenny Hoyos.
- Criar ficha do Template 03: Reveal visual / loop estilo Zach King.
- Criar ficha do Template 04: Produto / venda direta estilo Dollar Shave Club.
- Criar ficha do Template 05: Institucional / causa estilo Dove.

### Premiere

Para cada template:
- criar sequência vertical 1080x1920;
- definir duração padrão;
- criar marcadores dos 3 blocos;
- criar placeholders;
- criar tracks de vídeo e áudio;
- criar tela final padrão;
- salvar projeto-base;
- exportar um vídeo-teste curto.

### Documentação

- Escrever modo de uso de cada template.
- Registrar onde ficam os arquivos do Premiere.
- Registrar quais assets entram em cada template.
- Registrar próximos ajustes após teste.

## 4. Ordem sugerida de execução

1. Montar a tabela-mãe das referências virais.
2. Escolher os 5 primeiros templates da biblioteca.
3. Analisar 1 vídeo de referência por template.
4. Criar a ficha operacional dos 5 templates.
5. Começar pelo Template 01 no Premiere.
6. Testar o Template 01 com material real ou simulado.
7. Ajustar e salvar como versão 1.0.
8. Repetir para os Templates 02 a 05.
9. Criar índice geral da biblioteca.
10. Definir padrão de nomenclatura e uso.

## 5. Próximas 3 ações imediatas

1. Criar a tabela-mãe da biblioteca com os vídeos virais já curados.
2. Escolher os 5 templates iniciais:
   - Storytelling informativo
   - Desafio / transformação
   - Reveal / loop visual
   - Venda direta / produto
   - Institucional / causa
3. Fazer a ficha completa do Template 01: Storytelling informativo vertical, usando Nas Daily como referência principal.

## 6. Critério de avanço

Só avançar de uma fase para outra quando houver entregável claro.

### Fase 1 concluída quando:
- houver tabela com pelo menos 10 referências virais organizadas.

### Fase 2 concluída quando:
- pelo menos 5 referências tiverem análise em 3 blocos.

### Fase 3 concluída quando:
- existirem 5 fichas de template prontas.

### Fase 4 concluída quando:
- pelo menos 1 template estiver montado no Premiere.

### Fase 5 concluída quando:
- cada template tiver sido testado em 1 vídeo.

### Fase 6 concluída quando:
- a versão 1.0 de cada template estiver salva e documentada.
