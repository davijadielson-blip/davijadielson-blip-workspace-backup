# Métodos para enriquecer planejamentos — Central Pessoal

**Data:** 2026-07-20
**Origem:** Telegram `Central Pessoal > Alfred`
**Tipo:** resposta conceitual-operacional

## Base atual já registrada

O sistema pessoal de Jadielson já combina:

- Backlog Inteligente: capturar → clarear → fatiar → priorizar → agendar → executar → revisar.
- Método TDAH: protocolo de 10 minutos, microvitórias, rotina 70%, padrões de trava e fechamento sem julgamento.
- xTiles: cockpit visual/operacional humano.
- Google Calendar: camada de tempo.
- Cofre: memória, decisões e continuidade.
- Central/Agentes: inteligência para sintetizar, classificar e registrar.

## Métodos que podem enriquecer sem virar burocracia

### 1. GTD simplificado
Uso: capturar tudo, clarear próximas ações e separar compromissos de tarefas.
Aplicação: Inbox → clarear → próxima ação → agenda/backlog.

### 2. PARA
Uso: organizar informações por Projetos, Áreas, Recursos e Arquivo.
Aplicação: útil para xTiles/Cofre/Drive, evitando bagunça entre áreas da vida.

### 3. Eisenhower
Uso: separar urgente/importante.
Aplicação: escolher PDs e evitar urgência falsa.

### 4. Esforço x Impacto
Uso: decidir o que fazer primeiro quando há muitas opções.
Aplicação: escolher Micro PGs e melhorias rápidas.

### 5. Pareto 80/20
Uso: identificar poucas ações que geram maior resultado.
Aplicação: proteger horário nobre de Jadielson para ações que movem dinheiro, autoridade, entrega ou destravamento real.

### 6. Time Blocking
Uso: transformar intenção em bloco real de tempo.
Aplicação: Calendar como camada de realidade; não planejar mais do que cabe no dia.

### 7. Pomodoro / ciclos 90-30
Uso: execução com energia protegida.
Aplicação: 25 min para destravar; 90 min para trabalho profundo quando houver energia.

### 8. Kanban pessoal
Uso: visualizar fluxo.
Aplicação: A Fazer → Próxima Ação → Em andamento → Aguardando → Concluído.

### 9. OKR leve / Norte trimestral
Uso: ligar rotina diária a resultados maiores.
Aplicação: 1 a 3 objetivos por ciclo, com resultados mensuráveis simples.

### 10. SMART / critério de conclusão
Uso: deixar tarefas menos vagas.
Aplicação: verbo + objeto + contexto + critério de conclusão + prazo.

### 11. Revisão semanal
Uso: limpar atrasadas, revisar projetos, ajustar foco.
Aplicação: domingo ou segunda, com checklist fixo.

### 12. Método antifragilidade diária
Uso: plano A, plano B e plano mínimo.
Aplicação: para dias sequestrados por demandas externas.

## Recomendação de Alfred

Não adotar todos como sistemas separados. Criar um único protocolo híbrido:

1. Mapa 360 para visão geral.
2. Backlog Inteligente para capturar e fatiar.
3. PARA para organizar.
4. Eisenhower + Esforço x Impacto + Pareto para priorizar.
5. Time Blocking para posicionar no calendário.
6. Pomodoro/90-30 + Protocolo 10 minutos para executar.
7. Kanban para visualizar fluxo.
8. Revisão diária/semanal para manter vivo.
9. OKR leve para dar direção trimestral.
