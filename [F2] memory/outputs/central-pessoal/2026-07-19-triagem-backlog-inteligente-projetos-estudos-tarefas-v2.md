## Regra operacional ajustada

Projetos e estudos **não devem chegar ao tópico de tarefas como blocos grandes**.

O que deve chegar em **Tarefas** é apenas a **próxima ação fatiada**, em formato pequeno, claro, executável e com verbo de ação, conforme o Método Backlog Inteligente.

Formato recomendado:

`[Origem: Projeto/Estudo/Manutenção] — Microtarefa — contexto/prazo se houver`

# 1. PROJETOS — enviar para Projetos

## 1.1 Minidoc dos índios

**Tipo:** Projeto de produção audiovisual.  
**Não mandar como tarefa:** “fazer minidoc dos índios”.  
**Mandar para tarefas apenas as próximas ações fatiadas:**

- Abrir a pasta do material do minidoc dos índios.
- Listar os arquivos principais captados.
- Separar os arquivos em vídeo, áudio, fotos e apoio.
- Criar uma primeira timeline bruta.
- Anotar faltas de material ou informação.
- Definir o menor corte entregável.

## 1.2 Dois minidocs da Assembleia de Deus

**Tipo:** Projeto de produção audiovisual.  
**Não mandar como tarefa:** “fazer os dois minidocs”.  
**Mandar para tarefas apenas:**

- Separar o material da inauguração 1.
- Separar o material da inauguração 2.
- Criar pasta/timeline para o minidoc 1.
- Criar pasta/timeline para o minidoc 2.
- Listar cenas fortes de cada evento.
- Definir narrativa mínima de cada minidoc.

## 1.3 Entre Tempo / clipe

**Tipo:** Projeto criativo/audiovisual.  
**Não mandar como tarefa:** “resolver Entre Tempo”.  
**Mandar para tarefas apenas:**

- Listar entregáveis do Entre Tempo/clipe.
- Definir primeiro teaser mínimo.
- Separar materiais visuais existentes.
- Rascunhar ideia de aquecimento.
- Criar uma arte ou roteiro curto de chamada.

## 1.4 O Fio da Memória

**Tipo:** Projeto cultural/autoral em backlog.  
**Status:** não puxar agora se houver projetos com dinheiro/prazo pesando.  
**Mandar para tarefas apenas se for ativado:**

- Escrever escopo mínimo do projeto.
- Listar possíveis personagens/fontes.
- Definir primeiro produto mínimo.
- Separar referências já existentes.

## 1.5 Templates para vídeos e stories

**Tipo:** Subprojeto operacional / ativo reutilizável.  
**Mandar para tarefas:**

- Escolher um formato prioritário de template.
- Criar o primeiro modelo base de vídeo.
- Criar o primeiro modelo base de story.
- Testar o template em uma peça real.
- Ajustar nome, pasta e padrão de uso.

# 2. ESTUDOS — enviar para Estudos

## 2.1 Comunidade 1P

**Tipo:** Estudo estratégico aplicado.  
**Não mandar como tarefa:** “estudar Comunidade 1P”.  
**Mandar para tarefas apenas:**

- Assistir 20–30 minutos da próxima aula.
- Anotar 3 ideias aplicáveis.
- Escolher 1 aplicação prática para a LÓGIKA/vida empresarial.
- Transformar a ideia escolhida em uma microação.

## 2.2 Gestão do tempo — Rafael Medeiros

**Tipo:** Estudo aplicado à rotina.  
**Mandar para tarefas apenas:**

- Assistir um trecho/aula curta.
- Extrair uma regra prática.
- Comparar a regra com a rotina atual.
- Testar uma melhoria por 1 dia.
- Registrar o que funcionou ou travou.

## 2.3 CRM + Notion + Forms

**Tipo:** Estudo + sistema.  
**Destino primário:** Estudos enquanto for aula; Sistemas se virar implantação.  
**Mandar para tarefas apenas:**

- Assistir a aula sobre CRM/Notion/Forms.
- Anotar quais campos são necessários.
- Listar o fluxo ideal de entrada do lead.
- Criar rascunho do formulário.
- Definir onde o lead será acompanhado.

## 2.4 Skills eleja.se

**Tipo:** Estudo + automação/projeto.  
**Mandar para tarefas apenas:**

- Capturar o conteúdo/post base.
- Listar possíveis skills úteis.
- Escolher a primeira skill candidata.
- Escrever o objetivo da skill em uma frase.
- Separar exemplos de entrada e saída.

## 2.5 VENDE-C / cursos

**Tipo:** Estudo em backlog.  
**Status:** puxar apenas com janela real.  
**Mandar para tarefas apenas se for ativado:**

- Escolher um módulo curto.
- Assistir uma aula.
- Anotar uma ação comercial aplicável.
- Testar uma abordagem em pequena escala.

# 4. MANUTENÇÃO / SISTEMAS — não mandar como tarefa grande

## 4.1 Saúde/SMS

**Tipo:** Área de manutenção institucional.  
**Mandar para tarefas apenas demandas específicas:**

- Conferir pauta da semana da Saúde/SMS.
- Separar demanda de Julho Amarelo se houver.
- Conferir comunicados pendentes.
- Listar aniversários ou datas relevantes.

## 4.2 Organização de arquivos digitais e Google Drive

**Tipo:** manutenção/sistema.  
**Não mandar:** “organizar Drive”.  
**Mandar para tarefas apenas:**

- Escolher uma pasta para organizar.
- Listar arquivos soltos da pasta escolhida.
- Criar subpastas necessárias.
- Mover um lote pequeno de arquivos.
- Registrar padrão usado.

## 4.3 Financeiro LÓGIKA / planilha

**Tipo:** manutenção financeira/operacional da empresa.  
**Observação:** respeitar parede d’água; encaminhar para a frente correta de LÓGIKA/finanças empresariais, não misturar com vida pessoal.

**Mandar para tarefas apenas:**

- Abrir planilha financeira da LÓGIKA.
- Revisar categorias existentes.
- Listar contas recorrentes.
- Listar receitas previstas.
- Marcar pendências de atualização.

## 4.4 Música diária

**Tipo:** manutenção pessoal / identidade.  
**Mandar para tarefas apenas como microbloco:**

- Praticar música por 10–15 minutos.
- Escolher uma música/exercício do dia.
- Registrar prática feita.
