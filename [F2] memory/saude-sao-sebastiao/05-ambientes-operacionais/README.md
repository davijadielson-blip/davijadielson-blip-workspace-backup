## Regra de uso

Cada setor possui `ficha-operacional.md` com: o que faz, competência, pilar editorial, linguagem pública, cuidados e fontes.


## Padrão interno de cada setor

Cada subpasta de setor deve conter:

- `ficha-operacional.md` — resumo rápido para agentes.
- `conteudo-f1-incorporado.md` — cópia operacional consolidada das fontes F1 mapeadas.
- `servicos-e-competencias.md` — recorte dos serviços, funções, fluxos e competências.
- `fontes-f1-incorporadas.md` — lista das fontes usadas.
- `ideias-de-conteudo.md` — ideias e pautas extraídas das fontes.
- `lacunas-a-confirmar.md` — pontos que precisam validação antes de publicar.
