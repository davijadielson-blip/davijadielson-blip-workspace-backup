# Como triar o Inbox do Cofre — explicação para Jadielson

**Data:** 2026-07-12 / 2026-07-13 UTC  
**Origem:** Telegram — Central Pessoal / Alfred  
**Solicitante:** Jadielson Davi

## Ideia principal
Jadielson não precisa mexer em pastas nem abrir o Cofre manualmente para triar. A triagem deve acontecer conversando com Alfred/Arca no tópico da Central Pessoal.

O local técnico dos itens é o Inbox do Cofre:
- `/data/.openclaw/workspace/[F0] 0-Inbox/`
- `/data/.openclaw/workspace/\[F0\] 0-Inbox/` quando houver árvore duplicada/legada

## Como Jadielson faz na prática
Jadielson pode dizer:

> “Alfred, tria os 10 primeiros itens do Inbox do Cofre.”

Alfred lê os arquivos, monta uma lista simples com sugestão para cada item e pergunta antes de mover/excluir.

## Destinos possíveis
Para cada item, escolher um destino:

1. **Excluir** — teste, lixo, duplicado.
2. **Arquivar** — informação útil, mas sem ação.
3. **Virar tarefa PD** — obrigação, cobrança, manutenção, entrega pendente.
4. **Virar projeto/PG** — gera dinheiro, portfólio, crescimento ou sistema.
5. **Enviar para Arca** — material de conhecimento/contexto que precisa ser organizado.

## Fluxo seguro
1. Alfred lista os itens do Inbox.
2. Alfred sugere o destino de cada um.
3. Jadielson responde aprovando ou corrigindo.
4. Só depois Alfred move, arquiva ou deleta.

## Regra de ouro
Jadielson não deve triar dentro do servidor. Ele tria por decisão. Alfred executa tecnicamente no Cofre.
