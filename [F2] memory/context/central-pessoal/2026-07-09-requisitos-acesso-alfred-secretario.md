# Requisitos — Alfred secretário pessoal com roteamento entre grupos

**Data:** 2026-07-09
**Solicitante:** Jadielson Davi
**Agente:** Alfred / Central Pessoal

## Pedido confirmado por Jadielson
Jadielson confirmou que, entre as funções desejadas para Alfred como secretário pessoal, está a necessidade de **livre acesso e capacidade de encaminhamento a todos os grupos**, pois haverá conteúdos que Alfred precisará filtrar e encaminhar para o destino correto.

## Interpretação operacional segura
O requisito faz sentido para a função de secretário/triador, mas deve ser validado pela Lôh por envolver arquitetura, permissões, privacidade, segurança, roteamento transversal e paredes-d'água.

## Necessidades para validação com Lôh
1. Definir quais grupos/tópicos Alfred pode ler.
2. Definir para quais grupos/tópicos Alfred pode encaminhar mensagens.
3. Criar uma matriz de roteamento: tipo de demanda → destino correto.
4. Definir níveis de ação:
   - pode apenas sugerir encaminhamento;
   - pode preparar minuta;
   - pode encaminhar automaticamente;
   - precisa de confirmação de Jadielson.
5. Manter parede-d'água entre vida pessoal, LÓGIKA/clientes, estudos, finanças e projetos.
6. Definir logs obrigatórios no Cofre para rastreabilidade.
7. Confirmar com Lôh qualquer automação, integração, memória central ou permissão transversal.
