# Projetos fatiados — formato simples

**Data:** 2026-07-09
**Formato:** projeto → impacto → próximas fatias pequenas
**Regra:** transformar projeto em ações pequenas, visíveis e iniciáveis.

## 1. CRM + Notion + Forms
**Impacto:** organizar funil comercial e acompanhamento de oportunidades.

Fatias:
1. Separar link/acesso do CRM no Notion.
2. Assistir à aula do vínculo CRM + Forms.
3. Anotar o passo a passo da aula.
4. Fazer o vínculo básico.
5. Testar enviando um formulário falso.
6. Ajustar campos essenciais: nome, contato, interesse, origem, status.
7. Definir rotina de uso: quando abrir, atualizar e revisar.

## 2. Skills eleja.se
**Impacto:** criar diferencial estratégico para Câmara e vereadores.

Fatias:
1. Voltar no Instagram do eleja.se.
2. Printar o post/recomendação.
3. Extrair as recomendações principais.
4. Separar por temas: posicionamento, conteúdo, campanha, mandato, comunicação.
5. Criar primeira skill simples com uma função clara.
6. Testar a skill com um exemplo da Câmara/vereador.
7. Ajustar e salvar versão reaproveitável.

## 3. Proposta Francisco Euzébio
**Impacto:** possível cliente novo e entrada de receita.

Fatias:
1. Definir objetivo da proposta: que serviço ele quer contratar.
2. Listar dores/oportunidades dele.
3. Criar pacote simples de serviços.
4. Definir entregáveis mensais.
5. Definir preço ou faixa de investimento.
6. Montar proposta em texto/PDF.
7. Enviar para fechamento.
8. Se fechar, iniciar estratégia e calendário de produção.

## 4. Templates vídeos/stories
**Impacto:** otimizar produção em tempo real e reduzir retrabalho.

Fatias:
1. Listar formatos mais repetidos: evento, aviso, bastidor, depoimento, aniversário etc.
2. Escolher 1 formato prioritário.
3. Criar template base.
4. Testar com uma demanda real.
5. Ajustar identidade visual.
6. Duplicar para mais 2 formatos.
7. Organizar pasta de templates.

## 5. O Fio da Memória
**Impacto:** continuidade de projeto cultural estratégico.

Fatias:
1. Abrir/usar tópico próprio no grupo Projeto.
2. Ver o status atual.
3. Definir próxima entrega concreta.
4. Listar materiais já captados.
5. Listar materiais faltantes.
6. Definir próxima captação ou edição.
7. Registrar próximo marco no tópico do projeto.

## 6. Entre Tempos / pré-lançamento
**Impacto:** preparar percepção pública e destravar lançamento.

Fatias:
1. Definir objetivo do pré-lançamento.
2. Separar materiais disponíveis.
3. Escolher 3 ideias de teaser.
4. Editar o primeiro teaser.
5. Revisar e ajustar.
6. Alinhar artes/capas.
7. Publicar ou agendar primeira peça.

## 7. Minidoc dos índios
**Impacto:** avanço de entrega cultural/audiovisual.

Fatias:
1. Organizar imagens dos jogos.
2. Organizar narração.
3. Criar timeline inicial.
4. Montar primeira versão bruta.
5. Assistir e listar buracos narrativos.
6. Ver se precisa voltar para captar imagens complementares.
7. Fazer lista objetiva das imagens faltantes.

## 8. Lançamento do clipe
**Impacto:** destravar comunicação do lançamento e portfólio.

Fatias:
1. Confirmar materiais disponíveis.
2. Confirmar status das artes.
3. Definir linha de pré-lançamento.
4. Editar teaser 1.
5. Revisar teaser.
6. Preparar legenda/chamada.
7. Publicar ou agendar.
