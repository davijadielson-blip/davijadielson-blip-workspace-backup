# Backlog Inteligente — Macroáreas v1

**Data:** 2026-07-18 20:07 UTC  
**Origem:** Telegram `ESTUDOS`, tópico `Backlog Inteligente` (`topic_id: 489`).  
**Base:** árvore consolidada de 92 itens em 11 projetos raiz.  
**Pergunta:** se definíssemos macroáreas, como ficaria?

## Lógica adotada

As macroáreas ficam acima dos projetos raiz. Elas representam grandes frentes da vida/atuação de Jadielson. A estrutura fica:

```text
Macroárea
└── Projeto raiz
    └── Subprojetos
        └── Tarefas / metas / ações / frutos
```

## Observação importante

Uma mesma raiz pode tocar duas macroáreas. Exemplo:

- `Carreira e posicionamento` pode tocar **Vida Pessoal** e **Trabalho/LÓGIKA**.
- `Casa` pode tocar **Família/Casa** e **Finanças/Patrimônio**.
- `YouTube` pode tocar **Conteúdo/Audiovisual** e **Trabalho/Negócios**.

Para evitar confusão, cada projeto deve ter uma **macroárea principal** e, se necessário, uma **macroárea secundária**.
