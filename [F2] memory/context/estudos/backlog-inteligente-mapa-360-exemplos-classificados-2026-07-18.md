## Regra refinada

- Se é **vida/rotina/cuidado** → Pessoal.
- Se é **desenvolvimento da pessoa-profissional** → Profissional.
- Se é **obrigação/serviço/entrega/cliente/rotina operacional** → Trabalho.
- Se é **construção com começo, meio, fim ou evolução estruturada** → Projetos.
