# Prompt — xTiles criar Mission Control — Backlog Inteligente v5

**Data:** 2026-07-20  
**Origem:** Telegram `ESTUDOS`, tópico `Backlog Inteligente`.  
**Uso:** copiar e colar no xTiles AI para gerar o painel/sistema.

---

## Prompt para xTiles

Crie um workspace/painel visual chamado **Backlog Inteligente — Mission Control v5**.

O objetivo é criar um cockpit pessoal para organizar **áreas, projetos, subprojetos, tarefas, compromissos, backlog, agenda e revisão**, com foco em execução para uma mente com TDAH/energia variável.

Não quero apenas uma matriz de tarefas. Quero um sistema hierárquico e visual:

```text
Área / Tema → Projeto → Subprojeto → Tarefa → Subtarefa / Próxima ação
```

Use um estilo limpo, visual, modular, com cards, seções e cores suaves. O painel deve ser fácil de usar diariamente, sem ficar burocrático.

## Estrutura principal do workspace

Crie as seguintes páginas ou seções principais:

1. **Dashboard — Hoje**
2. **Inbox — Captura Bruta**
3. **Áreas / Temas**
4. **Projetos**
5. **Subprojetos**
6. **Tarefas**
7. **Agenda / Tempo**
8. **Matriz Eisenhower**
9. **Esforço x Impacto**
10. **Travados / Protocolo 10 min**
11. **Revisão Semanal**
12. **Templates**

## 8. Matriz Eisenhower

Crie quatro quadrantes com cores:

1. **Fazer agora** — urgente e importante — vermelho/rosa
2. **Planejar** — importante, não urgente — verde/azul
3. **Delegar** — urgente, mas pode não depender de mim — amarelo
4. **Revisar / eliminar** — baixo valor ou falso compromisso — cinza

Cada quadrante deve listar tarefas vinculadas da coleção principal.

---

## 9. Esforço x Impacto

Crie quatro quadrantes:

1. **Quick Wins** — alto impacto + baixo esforço — fazer primeiro
2. **Planejar para fazer** — alto impacto + alto esforço — planejar bem
3. **Executar quando possível** — baixo impacto + baixo esforço — quando sobrar
4. **Possibilidade de descarte** — baixo impacto + alto esforço — delegar/eliminar/incubar

---

## 10. Travados / Protocolo 10 min

Crie uma área para tarefas paradas.

Inclua os 7 padrões de trava:
- Perfeição
- Hiperfoco seletivo
- Evitação emocional
- Superestimação de tempo
- Sobrecarga de início
- Revisão infinita
- Colapso pós-esforço

Crie o protocolo:

```text
1. Nomear a tarefa travada.
2. Identificar o padrão de trava.
3. Reduzir para a menor ação.
4. Preparar ambiente.
5. Executar 10 minutos.
6. Decidir: continuar, pausar, reagendar ou descartar.
```

Tabela:
- Tarefa
- Padrão
- Menor ação
- Timer
- Decisão depois

## Botão / seção “Organizar com IA”

Crie uma seção com este prompt interno:

```text
Quando eu enviar uma lista solta, classifique cada item como área, projeto, subprojeto, tarefa, compromisso, ideia ou preocupação.

Para cada item:
1. Reescreva com clareza.
2. Se for tarefa, comece com verbo.
3. Defina área, projeto e subprojeto quando possível.
4. Sugira próxima ação.
5. Sugira prioridade P1/P2/P3.
6. Sugira impacto, complexidade e energia.
7. Sugira se entra em Hoje, Semana, Backlog, Agenda, Travados ou Incubação.
8. Se estiver vago, faça perguntas de clareza.
9. Se estiver travado, aplique o Protocolo 10 min.
```
