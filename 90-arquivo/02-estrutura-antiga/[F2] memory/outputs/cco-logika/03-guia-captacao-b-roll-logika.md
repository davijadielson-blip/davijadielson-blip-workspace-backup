# 📸 Guia de Captação — B-Roll Lógika Creative

**Documento:** CCO — Briefing de Captação Reutilizável  
**Data:** 20/07/2026  
**Status:** ✅ Vigente

---

## Princípio Fundamental

B-roll não é "enfeite" — é **camada de informação visual** que sustenta o discurso. Cada cena deve responder a uma pergunta ou provar uma afirmação.

---

## 1. Categorias de B-Roll por Tipo de Conteúdo

### Reels de Performance / Educativo

| Função | O que capturar | Enquadramento |
|---|---|---|
| **Mão na massa** | Mãos: escrevendo, editando, ajustando câmera, desenhando, mexendo no celular | Close / Plano detalhe |
| **Tela** | Celular/notebook com feed, editor, mensagem, resultado | Over-shoulder + tela limpa |
| **Reação** | Olhar pensativo, sorriso de insight, expressão de "é isso" | Primeiro plano (close) |
| **Ambiente** | Setup de trabalho, luz natural, mesa organizada, câmera | Plano médio / aberto |
| **Transição** | Movimento de câmera (pane, tilt, traveling) entre takes | Qualquer |

### Vídeos Institucionais

| Função | O que capturar | Enquadramento |
|---|---|---|
| **Contexto** | Local do cliente (fachada, sala, equipe trabalhando) | Plano aberto |
| **Humano** | Pessoa falando, atendendo, produzindo, interagindo | Meio / Close |
| **Prova** | Produto final, resultado, antes/depois, documento | Close / Detalhe |
| **Transição** | Time-lapse de movimento, porta abrindo, dia virando noite | Aberto |

### Cobertura de Eventos

| Função | O que capturar | Enquadramento |
|---|---|---|
| **Palco** | Apresentação, telão, palestrante, fala principal | Aberto + Close |
| **Público** | Plateia assistindo, aplaudindo, interagindo, celular gravando | Médio / Aberto |
| **Bastidor** | Preparação, equipamento, equipe, ajustes de última hora | Aberto + Detalhe |
| **Momento** | Gesto marcante, abraço, sorriso, emoção genuína | Close |
| **Detalhe** | Crachá, material gráfico, café, credencial, instrumento | Detalhe |

### Depoimentos / Prova Social

| Função | O que capturar | Enquadramento |
|---|---|---|
| **Entrevistado** | Pessoa falando em ambiente confortável (não parede branca) | Meio / Close |
| **Contexto** | Local onde a transformação aconteceu | Aberto |
| **Prova** | Print, documento, resultado físico | Tela / Detalhe |

## 2. Checklist Universal de Captação

### ⚙️ Técnico
- [ ] Resolução: pelo menos 1080p (4K preferencial)
- [ ] Taxa de quadros: 24fps (cinema) / 30fps (padrão) / 60fps (câmera lenta)
- [ ] Estabilização: ativada (gimbal ou tripé para cenas estáticas)
- [ ] Áudio ambiente captado (referência para edição)
- [ ] Cada cena tem no mínimo 5 segundos contínuos (liberdade na edição)

### 🎨 Composição
- [ ] Regra dos terços respeitada
- [ ] Fundo limpo ou com textura interessante (não parede vazia genérica)
- [ ] Iluminação natural ou artificial com direção clara (sem luz mista)
- [ ] Ponto de interesse claro no quadro

### 🎬 Cobertura
- [ ] Plano aberto (contexto)
- [ ] Plano médio (ação)
- [ ] Close (emoção/detalhe)
- [ ] Detalhe (textura/objeto)
- [ ] Plano de transição (mudança de cena, movimento)

### 🧠 Estratégico
- [ ] Cena de "antes" ou contexto
- [ ] Cena de "durante" ou processo
- [ ] Cena de "depois" ou resultado
- [ ] Cena humana (pessoas conectando, trabalhando, interagindo)
- [ ] Cena de identidade (logo, fachada, material da marca)

## 3. Regras de Ouro do B-Roll

### Faça
✅ Grave cenas com **pessoas reais**, não posadas — naturalidade ganha retenção
✅ Varie enquadramentos da mesma ação (aberto + médio + close) — segurança na edição
✅ Capture **movimentos orgânicos** (andar, falar, gesticular, escrever, digitar)
✅ Grave silêncio de cada ambiente (room tone) — salva edição
✅ Tenha cenas de **"respiro"** (paisagem, luz, textura) — transições elegantes

### Evite
❌ Cenas tremidas sem intenção (câmera na mão sem estabilização)
❌ Zoom digital (perde qualidade — mova a câmera)
❌ Fundo confuso ou poluído visualmente
❌ Pessoas olhando fixo pra câmera em cena de B-roll (quebra imersão)
❌ Exposição estourada (branco queimado) ou subexposta (preto sem textura)

## 4. Banco de Planos Coringa (Sempre Úteis)

| Cena | Uso |
|---|---|
| Mãos digitando no teclado | Processo, trabalho, criação |
| Xícara/copo sobre a mesa | Transição, pausa reflexiva |
| Tela de celular com feed | Rede social, resultado, métrica |
| Pessoa caminhando em direção à câmera | Abertura, chegada, início |
| Plano detalhe de material gráfico | Prova de entrega, qualidade |
| Livro/caderno aberto com caneta | Planejamento, estratégia |
| Close de olhos | Emoção, insight, conexão |
| Plano aberto do local | Contexto, ambientação |
| Janela com luz natural | Estética limpa, transição |
| Relógio / passagem de tempo | Urgência, rotina, processo |

---

## 5. Como Usar Este Guia

1. **Antes da captação:** marcar no checklist o que é obrigatório para o formato
2. **Durante a captação:** ter o checklist aberto e riscar conforme grava
3. **Após a captação:** anexar as cenas capturadas ao roteiro no template de produção
4. **Na edição:** puxar do banco de planos coringa se faltar alguma transição
