# 9. TRAVADOS / PROTOCOLO 10 MIN

> Para tarefas que ficam paradas por resistência, culpa ou sobrecarga.

## Padrões de trava

- Perfeição;
- Hiperfoco seletivo;
- Evitação emocional;
- Superestimação de tempo;
- Sobrecarga de início;
- Revisão infinita;
- Colapso pós-esforço.

## Protocolo

```text
1. Nomear a tarefa travada.
2. Identificar o padrão de trava.
3. Reduzir para menor ação.
4. Preparar ambiente.
5. Executar 10 minutos.
6. Registrar se continua, pausa ou reagenda.
```
