# Fatiamento inteligente v2 — Biblioteca de Templates de Vídeo

Data: 2026-07-19  
Tópico: PROJETOS > Templates  
Responsável: Jadielson / execução assistida pela Central  
Projeto: Biblioteca de templates de produção de vídeo para Premiere baseada em vídeos de alta performance

## 1. Objetivo em uma frase + como medir sucesso

Criar uma primeira biblioteca utilizável com 5 templates de vídeo vertical para Premiere, derivados de vídeos reais de alta performance, cada um com ficha de estrutura, referência viral, roteiro-base, timeline marcada e teste prático exportado.

### Medida de sucesso

O projeto será considerado bem-sucedido quando existirem:
- 5 templates documentados;
- 5 projetos-base ou timelines no Premiere;
- 1 vídeo-teste exportado por template;
- cada template organizado na lógica: Gancho / Abertura → Desenvolvimento / Solução → CTA / Encerramento;
- tempo médio de montagem estimado menor que editar do zero.

### Suposições a confirmar

- Prazo: não definido; proposta operacional: fechar a versão 1.0 em 2 semanas.
- Executor principal: Jadielson ou editor designado.
- Ferramentas: Premiere Pro, referências virais já curadas, Cofre para documentação.
- Escopo inicial: vídeos verticais de 30s a 60s.
- Restrições legais: copiar estrutura, ritmo e mecânica; não copiar identidade visual proprietária, música, roteiro literal ou marca.

## 2. Mapa de fases

1. Definir o pacote mínimo viável da biblioteca.
2. Converter referências virais em modelos copiáveis.
3. Produzir fichas de template prontas para edição.
4. Montar os templates no Premiere.
5. Testar, ajustar e fechar a versão 1.0.

## 4. Caminho crítico

Caminho crítico para o projeto sair do papel e gerar valor rapidamente:

1. Definir os 5 tipos de template da v1.
2. Definir padrão único de ficha.
3. Selecionar referência principal do Template 01.
4. Decompor o Template 01 em 3 blocos.
5. Criar ficha pronta do Template 01.
6. Montar projeto-base do Template 01 no Premiere.
7. Exportar vídeo-teste do Template 01.
8. Corrigir e salvar Template 01 v1.0.

Esse caminho entrega o primeiro ativo utilizável antes de tentar completar a biblioteca inteira.

## 5. O primeiro passo — uma só ação

Fechar agora os 5 tipos da v1 com esta lista inicial:

1. Template 01 — Storytelling informativo vertical, referência: Nas Daily.
2. Template 02 — Desafio / transformação, referência: Jenny Hoyos.
3. Template 03 — Reveal / loop visual, referência: Zach King.
4. Template 04 — Venda direta / produto, referência: Dollar Shave Club ou Blendtec.
5. Template 05 — Institucional / causa, referência: Dove Real Beauty Sketches.

## 6. Riscos e suposições

### Riscos

- Tentar criar muitos templates antes de validar o primeiro.
- Confundir referência viral com cópia estética.
- Criar ficha bonita, mas pouco útil para edição real.
- Fazer templates longos demais para a rotina de produção.
- Depender de métricas externas que mudam com o tempo.

### Suposições

- A biblioteca v1 começa com 5 templates, não com todos os formatos possíveis.
- O Template 01 deve ser o primeiro porque destrava o padrão dos demais.
- A documentação oficial fica no Cofre em Markdown.
- Arquivos do Premiere ficam fora do Cofre, em pasta de produção/Drive, porque o Cofre aceita apenas .md.
- O objetivo principal é acelerar produção, não criar uma tese sobre viralidade.
