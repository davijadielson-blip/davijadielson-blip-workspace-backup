# Decisões — 24/07/2026

## 1. 🛑 Política de Agentes Dormentes (DEFINITIVA)

**Contexto:** Jadielson já havia solicitado em 21/07/2026 que agentes ficassem "dormindo" e só acordassem sob demanda. A demanda ficou pendente. Hoje (24/07), agentes C-Level despertaram autonomamente e em cadeia durante testes de spawn, gerando consumo excessivo de créditos OpenRouter.

**Decisão:**
> **🚫 Agentes NÃO acordam sozinhos.**
> **✅ Só acordam quando:**
> - Requisitados diretamente por Jadielson
> - Requisitados pela Lôh (sob demanda)
> - Via cron programado e explícito (futuro)
>
> **Regra de escalonamento:** Se um agente detectar que outro agente seria útil, NÃO o desperta — reporta de volta para Lôh, que decide.

**Aprovado por:** Jadielson Davi

## 2. ✅ Correção de Modelo Primário

**Problema:** `agents.defaults.model.primary` apontava para `openai/gpt-5.1-codex` — modelo errado e não-Codex. Agentes estavam caindo em fallback OpenRouter.

**Correção aplicada:**
- `agents.defaults.model.primary` → `openai-codex/gpt-5.5` ✅
- Todos os 21 agentes em `agents.list` com primário `openai-codex/gpt-5.5` ✅
- Subagents com primário `openai-codex/gpt-5.5` ✅
- Gateway reiniciado via SIGUSR1 ✅

**Aprovado por:** Jadielson Davi

## 3. 🔴 Auditoria de Créditos OpenRouter

**Causa raiz do consumo excessivo:**
1. Agentes despertaram autonomamente em cadeia (testes C-Level)
2. Sessão principal e subagentes rodando em OpenRouter (fallback)
3. Sem política de agentes dormentes implementada

**Ações corretivas:**
- Política de agentes dormentes registrada (decisão #1 acima)
- Modelo primário corrigido para Codex (decisão #2 acima)
- OpenRouter mantido como fallback apenas

**Aprovado por:** Jadielson Davi

## 4. 🧪 Política de Testes — Economia de Créditos

**Contexto:** Testes (como spawn de agentes C-Level) consomem recursos. Se o Codex não estiver disponível ou funcionando bem, o fallback automático para OpenRouter queima créditos desnecessariamente.

**Decisão:**
> **🧪 Testes SÓ devem ser executados quando o Codex estiver operacional.**
>
> - Se Codex estiver fora ou instável, **testes são adiados** — não usam fallback OpenRouter
> - Fallback OpenRouter é para **operação real** (demandas de Jadielson), não para testes
> - Antes de qualquer bateria de testes, Lôh verifica se o Codex está responsivo
> - Se Codex falhar durante testes, a bateria é **interrompida e reagendada**

**Aprovado por:** Jadielson Davi
