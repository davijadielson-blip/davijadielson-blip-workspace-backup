# Backlog Inteligente — Prompt padrão de fatiamento inteligente

**Data:** 2026-07-19 03:19 UTC  
**Origem:** Telegram `ESTUDOS`, tópico `Backlog Inteligente` (`topic_id: 489`).  
**Formato:** áudio de Jadielson transcrito.

## Decisão registrada

Jadielson decidiu criar um **prompt neutro e padrão** para fatiamento inteligente de tarefas, a ser usado em cada tópico/agente específico — seja de projetos, estudos ou outras frentes.

## Objetivo do prompt

O prompt deve permitir que qualquer tópico/agente, ao receber uma demanda/projeto/subprojeto, consiga:

1. Diagnosticar se a demanda é tarefa simples, projeto ou subprojeto.
2. Se for projeto/subprojeto, fazer o fatiamento em etapas e tarefas executáveis.
3. Mostrar os caminhos possíveis.
4. Sugerir sequência de execução.
5. Ajudar Jadielson a enxergar o próximo passo claro.

## Diretriz operacional

O fatiamento não deve ficar concentrado apenas no tópico Backlog Inteligente. Este tópico define o método, mas a aplicação prática deve acontecer nos tópicos correspondentes:

- Projetos culturais → tópico/grupo PROJETOS.
- Estudos → tópicos de ESTUDOS correspondentes.
- Trabalho/LÓGIKA → tópicos/frentes apropriados de trabalho.
- Pessoal → tópicos pessoais/rotina, mantendo parede-d'água.

## Estrutura esperada do prompt padrão

```text
1. Diagnóstico
   - Isto é tarefa, projeto ou subprojeto?
   - Qual eixo do Mapa 360?
   - Qual resultado esperado?

2. Fatiamento
   - Quais são as fases?
   - Quais são os subprojetos?
   - Quais tarefas precisam ser executadas?

3. Priorização
   - O que é urgente?
   - O que destrava o restante?
   - O que pode esperar?

4. Execução
   - Próximas 3 ações físicas.
   - Janela sugerida na agenda.
   - Critério de concluído.

5. Clareza final
   - Resumo do caminho.
   - Primeiro passo recomendado.
```
