# Projeto/Tópico — Templates de Produção de Vídeo

**Data:** 2026-07-18
**Origem:** Telegram `PROJETOS > Jack Lemley`, áudio de Jadielson.
**Tópico criado:** `Templates`
**Topic ID Telegram:** `866`

## Pedido de Jadielson
Criar um tópico para trabalhar a criação de templates que otimizem o fluxo de trabalho de produção de vídeo.

## Ideia central
Desenvolver templates de edição, especialmente para Premiere, com linhas do tempo pré-estruturadas para facilitar a montagem de vídeos futuros em diferentes cenários.

## Estrutura percebida por Jadielson
Vídeos clássicos:
1. Abertura
2. Desenvolvimento/meio
3. Final/encerramento

Vídeos para redes sociais:
1. Gancho
2. Desenvolvimento
3. Solução ou promessa de solução
4. CTA/encerramento — reação, curtida, compartilhamento, comentário etc.

## Objetivo operacional
Criar uma biblioteca de templates reutilizáveis para acelerar produção, padronizar qualidade e reduzir retrabalho.

## Primeiras frentes de trabalho sugeridas
1. Template base para Reels/Shorts/TikTok.
2. Template para vídeo institucional curto.
3. Template para cobertura de evento.
4. Template para depoimento/fala direta.
5. Template para anúncio/aviso público.
6. Template para bastidor/making-of.
7. Template para projeto documental/cultural.

## Próximo passo
No tópico `Templates`, levantar os formatos mais repetidos e escolher o primeiro template a desenhar: provavelmente Reels/Shorts com estrutura `gancho → desenvolvimento → solução/promessa → CTA`.

## Ajuste decidido no tópico — Estrutura em 3 partes
**Data:** 2026-07-18
**Origem:** Telegram `PROJETOS > Templates`.

Jadielson ajustou a estrutura base dos templates: em vez de separar `Desenvolvimento` e `Solução/promessa de solução`, considerar que os dois cumprem a mesma função narrativa na maioria dos vídeos.

### Estrutura simplificada aprovada
1. **Gancho / abertura** — prende atenção e apresenta o motivo do vídeo.
2. **Desenvolvimento / solução** — entrega a informação, mostra o processo, explica, prova ou resolve.
3. **CTA / encerramento** — orienta a próxima ação, fecha a ideia ou reforça a marca.

### Observação operacional
Para templates de edição no Premiere, usar três blocos macro como padrão. Quando necessário, o bloco 2 pode ser subdividido internamente em cenas/takes sem virar uma quarta etapa narrativa.
