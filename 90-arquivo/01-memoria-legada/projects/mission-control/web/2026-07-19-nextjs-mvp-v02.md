Jadielson autorizou prosseguir após a recomendação de migrar o protótipo estático para uma base Next.js simples, ainda sem Notion.

## O que mudou em relação ao protótipo estático

- O dashboard deixou de ser HTML único.
- Dados foram separados em `lib/missionData.js`.
- Componentes foram separados em `components/`.
- Estrutura Next.js criada com `app/`.
- Build de produção testado.
- Servidor dev testado.
