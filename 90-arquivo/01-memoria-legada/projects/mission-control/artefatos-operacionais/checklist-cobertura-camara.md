# Checklist de Cobertura — Câmara Municipal

**Status:** v0.1 ativo  
**Frente:** Câmara Municipal  
**Uso:** sessão ordinária, sessão especial, evento, reunião ou cobertura institucional.

## 1. Antes da cobertura

- [ ] Data e horário confirmados.
- [ ] Local confirmado.
- [ ] Tipo de sessão/evento definido.
- [ ] Pautas principais levantadas.
- [ ] Pessoas-chave identificadas.
- [ ] Equipamentos carregados.
- [ ] Cartões/memória livres.
- [ ] Áudio testado.
- [ ] Plano de captação definido.

## 2. Durante

- [ ] Abertura/ambiente.
- [ ] Mesa/diretoria.
- [ ] Vereadores em fala.
- [ ] Público/participação, se adequado.
- [ ] Momentos de votação/deliberação.
- [ ] Imagens de apoio.
- [ ] Áudios ou falas-chave anotadas.

## 3. Depois

- [ ] Backup feito.
- [ ] Seleção inicial feita.
- [ ] Melhores momentos anotados.
- [ ] Entregáveis definidos: reels, feed, stories, vídeo longo, release.
- [ ] Prazo de edição definido.
- [ ] Publicação/entrega registrada.

## 4. Critério de pronto

A cobertura está pronta quando:

- material foi salvo;
- backup feito;
- melhores momentos separados;
- entrega definida;
- status registrado no Mission Control.
