# Inbox externa consolidada

A inbox externa deixou de ser rota ativa separada.

Use a inbox unica do Cofre:

`00-central/inbox/`

Para entradas vindas de Drive, Gmail, WhatsApp, audio, Notion ou automacoes, use:

`00-central/inbox/externa/`

Este arquivo existe apenas para compatibilidade e rastreabilidade. Nao salve conteudo novo nesta pasta.
