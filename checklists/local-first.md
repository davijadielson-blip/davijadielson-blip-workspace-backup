# ✅ Checklist LOCAL-FIRST

> **Consulte o Cofre primeiro. Sempre.**

## Antes de responder

- [ ] 1. Já consultei o Cofre (`/data/.openclaw/workspace/`)?
- [ ] 2. Li o `MAPA.md` para saber onde procurar?
- [ ] 3. Li `AGENTS.md`, `MEMORY.md`, `USER.md` (se relevante)?
- [ ] 4. Busquei em `memory/` (diários, decisões, contexto)?
- [ ] 5. Se `memory_search` falhou, fiz fallback direto (read/find/grep)?
- [ ] 6. Informei de onde veio cada dado (arquivo + pasta + trecho)?
- [ ] 7. Se não achei nada, disse claramente?
- [ ] 8. Só depois disso usei Tavily/Internet?

## Se a resposta for NÃO em qualquer item acima

> ⛔ **PARE.** Consulte o Cofre agora.  
> Falha operacional → registre em `memory/lessons.md`.

## Depois de responder

- [ ] Salvei no Cofre o que for pertinente para continuidade?
- [ ] Incluí rodapé de fonte?
- [ ] Aprendizado deve ir para `memory/lessons.md`?
