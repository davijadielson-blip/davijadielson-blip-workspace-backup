# 70-agentes

## Finalidade
Esta pasta concentra mapa, escopos, protocolos e materiais de agentes.

## Regra de uso
Agentes podem criar e editar arquivos aqui quando a tarefa exigir, respeitando contexto mínimo necessário, YAML frontmatter, citação de fontes, separação entre fato/hipótese/sugestão e registro de decisões/pêndencias nos arquivos centrais.

## Não colocar aqui
- Segredos, tokens ou chaves privadas.
- Arquivos não-`.md` novos.
- Decisões transversais sem registrar em `00-central/decisoes.md`.
- Materiais de outra área sem link/justificativa.
