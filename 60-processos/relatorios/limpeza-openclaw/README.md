# Relatorios de limpeza do OpenClaw

Esta pasta guarda os relatorios diarios ou pontuais da rotina de governanca de memoria e armazenamento do OpenClaw.

Cada relatorio deve informar:

- data e hora;
- uso antes;
- uso depois;
- espaco liberado;
- arquivos removidos ou isolados;
- sessoes preservadas;
- itens pendentes de revisao;
- possivel causa do crescimento;
- acao preventiva recomendada.

Regra: nao salvar aqui raciocinio descartado nem logs brutos sem utilidade. O relatorio deve ser curto, auditavel e suficiente para continuidade.
