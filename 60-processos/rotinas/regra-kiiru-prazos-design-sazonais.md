# Regra Kiiru - prazos de design para artes sazonais

## Regra operacional

Quando uma tarefa sazonal no Kiiru tiver uma data no inicio do titulo, essa data deve ser tratada como a **data prevista de publicacao**.

O prazo de entrega do design deve ser definido como **7 dias antes da data de publicacao**.

Exemplo:

- Titulo: `15/10: Dia do Professor`
- Publicacao prevista: `2026-10-15`
- Prazo de entrega do design: `2026-10-08`

## Como aplicar

1. Ler a primeira data do titulo da tarefa.
2. Interpretar essa data como publicacao prevista.
3. Definir `entrega` no Kiiru para 7 dias antes.
4. Se a tarefa ja estiver em producao, aprovada, agendada, publicada ou na lixeira, conferir o status antes de alterar.
5. Se o titulo nao trouxer data, nao inventar automaticamente; buscar calendario sazonal do cliente ou perguntar a Jadielson quando houver risco de erro.
