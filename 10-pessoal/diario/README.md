# Diario pessoal

Esta pasta e a rota ativa para relatos breves de fim de dia de Jadielson.

## Objetivo

Registrar, em poucos minutos, como foi o dia:

- o que foi feito;
- o que nao foi feito;
- o que avancou;
- o que travou;
- o que foi conquistado;
- o que precisa voltar para o planejamento.

A finalidade nao e cobrar perfeicao. E criar historico para medir, com mais honestidade, se o que foi planejado esta virando pratica.
