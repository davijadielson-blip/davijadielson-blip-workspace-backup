## Causa
O token OAuth do Google Calendar (`/data/.openclaw/workspace/scripts/.secrets/google-calendar-token.json`) expirou e o refresh_token também foi revogado. O script tentou refresh automático mas falhou com `invalid_grant`.

## Ação necessária
Reautenticação manual OAuth via navegador é necessária:

1. Executar script de reautenticação:
   ```bash
   cd /data/.openclaw/workspace
   python3 -c "
   import json, os
   from pathlib import Path
   from google_auth_oauthlib.flow import InstalledAppFlow

   creds_file = Path('scripts/.secrets/google-calendar-credentials.json')
   flow = InstalledAppFlow.from_client_secrets_file(str(creds_file), ['https://www.googleapis.com/auth/calendar'])
   creds = flow.run_local_server(port=0)
   Path('scripts/.secrets/google-calendar-token.json').write_text(creds.to_json())
   print('Token renovado com sucesso!')
   "
   ```

2. Após reautenticação, rodar novamente:
   ```bash
   python3 scripts/sync/notion-to-calendar.py
   ```
