# Tópico 1224 — 🎬 CapCut Reels

## Finalidade
Produção de vídeos curtos para Instagram Reels utilizando o CapCut Web via navegador. Edição, cortes, trilha, legendas e exportação.

## Regra operacional do tópico
Ao receber novas mensagens neste tópico, o agente deve:
1. Tratar como produção de conteúdo para Instagram Reels.
2. Organizar todo o contexto: briefings, referências, material bruto (links de Drive), decisões editoriais, roteiros, cronograma.
3. Manter arquivos de mídia no Google Drive (não salvar binários no Cofre).
4. Registrar decisões, próximos passos e andamentos no Cofre.
5. Ao final de cada Reel produzido, registrar: link de preview, link de exportação, duração, estilo, observações.
