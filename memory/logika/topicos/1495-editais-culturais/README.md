# Tópico 1495 — 📋 Editais Culturais

## Finalidade
Receber, analisar e classificar editais culturais (leis de incentivo, prêmios, chamadas públicas, fomento). O agente deve extrair os dados essenciais, avaliar aderência e sugerir próximos passos.

## Regra operacional do tópico
Ao receber novas mensagens neste tópico, o agente deve:

1. **Analisar o edital** enviado (link, PDF anexado ou texto colado)
2. **Extrair os dados essenciais:** órgão/instituição, prazo, valor/recursos, área cultural (música, audiovisual, artes cênicas, patrimônio, etc.), requisitos de inscrição, documentação necessária, contrapartidas, cronograma completo
3. **Classificar a aderência:** 🔴 Baixa / 🟡 Média / 🟢 Alta — com justificativa objetiva
4. **Sugerir próximos passos:** inscrever, preparar documentação, solicitar orçamento, compartilhar com parceiro X
5. **Salvar no Cofre** toda análise em `[F3] PROJETOS/03_PROJETOS/01_Autorais_Culturais/Editais Culturais/` com nome padronizado (`edital-NOME-DATA.md`)
6. **Manter calendário** de prazos — alertar sobre vencimentos próximos
7. **Não tomar decisão** de inscrição sem aprovação de Jadielson
